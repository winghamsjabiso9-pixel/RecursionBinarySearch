# Laboratory Activity: Recursion



# Description:

This program takes array size and elements, sorts them ascending, searches for your target number, display low, high,mid, and tells you if it was found with its index or not found with index -1.


# Programming language used

Java

# Instructions for compiling/running the program

Compiling:
javac BinarySearchRecursive.java

Running:
java BinarySearchRecursive

# Sample input and output
( Input )
Enter number of elements: 7
Enter 7 integers:
Element 1: 70
Element 2: 20
Element 3: 50
Element 4: 10
Element 5: 40
Element 6: 30
Element 7: 60

( Output )
Sorted Array: [10, 20, 30, 40, 50, 60, 70]

( Input )
Enter the number you are looking for: 50

( Output )
--- Recursion Trace ---
low = 0 | high = 6 | mid = 3
low = 4 | high = 6 | mid = 5
low = 4 | high = 4 | mid = 4
--- End of Trace ---

Target Found
Index: 4
